# AstroAI — ML Project Report Template

## Abstract
Describe the problem of identifying celestial objects in ordinary smartphone night-sky images and the hybrid deep-learning + astronomy approach.

## Problem statement
A normal star is essentially a point source in a phone image, so exact identity depends on the surrounding star-field geometry and observation metadata.

## Objectives
1. Detect usable stellar point sources in smartphone images.
2. Use a neural model to verify likely point sources.
3. Solve the camera field of view/orientation against a visible-star catalog.
4. Identify named stars and infer constellations.
5. Check predicted planet locations using observation time and location.

## Dataset
- HYG v4.1 visible-star subset.
- Synthetic star/non-star patches generated by `scripts/train_star_detector.py`.
- Real smartphone photos collected for held-out testing.

## Model
Explain the compact CNN architecture in `src/star_ml.py` and why it is used for point-source verification rather than direct star-name classification.

## Astronomy layer
Explain RA/Dec, Alt/Az, observer location, observation time, camera projection, and catalog matching.

## Experiments
Compare:
- classical star detection only,
- CNN-verified star detection,
- sensitivity to field-of-view settings,
- sensitivity to blur/light pollution/few stars.

## Metrics
Report precision, recall, F1 for star detection; constellation top-1/top-3 accuracy; number of correct named-star matches; planet-match accuracy; and solve failure rate.

## Limitations
Discuss synthetic-to-real domain shift, lens distortion, missing EXIF, exposure, clouds, and insufficient star count.

## Future work
Learned star-field embeddings, no-GPS solving, device orientation, richer Gaia data, and live camera inference.
